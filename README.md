# NetConfigPro 网络设备配置专家

支持 **华为 / 华三 / 思科 / 锐捷** 四大厂商，覆盖 **路由器 / 防火墙 / 三层交换机 / 无线 AP** 的 C# WPF 桌面配置生成工具。**浅色科技风 UI**（清晰可读），自包含单文件 exe，双击即用、免装 .NET 运行时。

## 功能特性

- **皮肤外观**：内置 **32 种主色**（标题栏「调色板」图标一键切换，主色派生选中/悬停/渐变/发光整体换肤），选择即时生效并自动记忆，重启保持。
- **生成器**：38 大类配置按厂商语法生成，注释风格华为/华三/锐捷 `#`、思科 `!` 自适应；输出带层级缩进与章节分隔；**路由可多选并存（静态+OSPF+BGP+RIP/EIGRP）**；支持「从设备清单载入」（自动带入厂商/类型并预填主机名/管理 IP）。生成页 **「复制」= 纯命令**（自动剥离 `#`/`!` 注释与分隔线，可直接粘贴到设备终端）；**「导出」= 完整版**（含注释，适合离线存档与阅读）。
- **提效交互**：功能模块列表**搜索过滤**；**方案预设**一键勾选（小型办公出口/出口双线/标准园区接入/三层汇聚/无线热点/运维全开）；**生成前合法性预检**（重复 VLAN、编号越界、IP 非法、ACL 号段、端口映射非数字等以"⚠ 提醒"注入输出头部，不阻断生成）；**批量生成**（名称前缀 + 起始管理 IP 递增，1~99 份纯命令 .cfg 一次导出）。
- **一键巡检**：按厂商 × 设备类型输出**特权视图只读诊断命令集**（5 大组 21 项 × 4 厂商），按设备过滤（仅交换机看 MAC/VLAN/STP、仅防火墙看会话表等），支持中文注释版/纯命令两种模式（**复制/导出纯命令可直接粘贴到设备终端**）。
- **网络命令**（第 10 个导航页）：**Windows 运维本机**诊断命令合集 —— 6 组 26 条（连通性 ping/tracert/pathping/Test-NetConnection、DNS nslookup/ipconfig、ARP/IP/MAC、netstat/route、HTTP curl 探测、无线 netsh），填目标一键生成注释版+纯命令，可**直接在软件内执行**（后台逐条运行、结果实时显示、超时自动终止，`ping -t`/`telnet` 等交互式命令自动降级或跳过）；仅用 Windows 10/11 自带工具。
- **真实 SSH 下发**（批量部署页）：部署从模拟升级为**直连设备真下发** —— 附带 PuTTY plink（密码直连，需与 exe 同目录）或系统 OpenSSH（密钥免密）双通道；自动关闭分页 → 逐行下发 → 返回视图 → 保存（save/save force/write），逐台日志分级；下发前厂商一致性校验、enable 密码输入（思科/锐捷）。
- **现网配置导入**（生成器）：把设备 `running-config` 导出文本粘贴进来 → **自动识别厂商 → 回填主机名/管理地址/网关/DNS/VLAN/静态路由**核心参数，ACL/NAT/账号等以清单提示人工核对，秒变“拿现网改需求”。
- **最近方案**（生成器左栏）：成功生成自动记忆最近 10 条（厂商×设备×全参数快照），可命名保存/一键载入/删除，同类设备不用重填。
- **厂商偏好记忆**（生成器「预设」菜单）：成功生成时自动记住该“厂商×设备类型”勾选了哪些模块；下次打开软件或切回该组合且未勾选时**自动恢复常用模块**（可在预设菜单里手动记住/清除）。
- **IP-MAC 地址扫描**（第 10 个导航页）：填网段（CIDR/区间/单 IP/多段逗号）→ 并发 ping 触发 ARP 解析（被禁 ping 的设备也能发现）→ 列出在线主机 IP↔MAC 并内置常用 OUI 厂商识别（华为/华三/思科/锐捷/TP-Link/小米/苹果/海康/大华/腾达 等 ~50 条）；自动补齐本机行（即便不在 ARP 表）；支持复制 / CSV 导出（带 BOM，Excel 不乱码）。
- **一键交付包**（第 10 个导航页）：把「版本管理」的配置或本地 .cfg **勾选打包成 ZIP**——自动按设备分组载入最近版本、可追加文件，包内自动写入**交付说明.txt**（文件清单/使用步骤/配置概要），发给客户零手工整理（内置压缩库，零依赖）。
- **命令手册**（生成器「当前选择」卡）：内置 10 大主题 × 关键命令语法与厂商差异（官方资料审计），随点随查。
- **检查报告**（网络命令页 / 报告窗口）：把命令执行结果自动提取“异常/注意”问题清单 → 一键导出**客户版 HTML/MD 报告**（设备信息、问题表、结论建议、原始输出附录）。
- **设备管理**：维护可批量操作的设备资产清单（密码 AES 本机混淆存储）。
- **批量部署**：同一份配置批量下发（模拟执行 + 厂商语法一致性提示）。
- **配置对比**：左右两栏 LCS 行级比对，新增/删除/相同差异高亮，超大文本自动降级。
- **模板库**：参数集合存为模板、一键套用还原。
- **版本管理**：配置自动归档编号，支持回看/复制/导出/载入对比。
- **导出**：`.cfg` / `.txt` / CSV（UTF-8）。

## 启动方式

双击 `NetConfigPro.exe` 即用（win-x64 自包含单文件，约 64 MB，无需安装 .NET）。

> **真实 SSH 下发需配套文件**：把同目录的 `plink.exe`（PuTTY，约 1 MB）与 `NetConfigPro.exe` 放一起即可用密码直连真机；不放则自动退回系统 OpenSSH 密钥通道。

## 操作流程

1. 左侧选择 **厂商平台** 与 **设备类型**（模块列表按设备自动过滤）。
2. **功能模块** 勾选要生成的类别（页签自动换行展示；切换设备后不再适用的勾选自动清除）。
3. 中间表单按页签填写参数（表格类可直接输入新行）。
4. 右侧 **生成配置** → 语法高亮输出；**复制 / 导出 / 存为版本 / 存为模板**。
5. 参数支持 `10-20` VLAN 区间、`A to B` 接口区间、`any` 等便捷写法。

## 注意事项

生成配置基于各厂商主流 VRP / Comware V7 / IOS / RGOS 通用命令整理，**上设备前请按具体型号与软件版本核对**；防火墙等专用平台的个别命令（如 ASA failover、USG 域策略）建议再对照手册微调。
